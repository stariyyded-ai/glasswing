# Glasswing

Стеклянные виджеты для рабочего стола Windows 10 и 11 в одном приложении: часы, монитор системы, «Сейчас играет», переводчик, питомец, игровой хаб и другие. Без новостей и рекламы.

## Установка

Скачайте **Glasswing.exe** из последнего [релиза](../../releases/latest) и запустите. Он сам установится в `%LOCALAPPDATA%\Programs\Glasswing`, добавит ярлык в «Пуск» и встанет в автозапуск. Удаление: «Параметры → Приложения → Glasswing».

Если Windows покажет окно SmartScreen «Неизвестный издатель», нажмите «Подробнее» → «Выполнить в любом случае».

## Обновления

Glasswing раз в день проверяет последний релиз этого репозитория. Если вышла версия новее, он предлагает обновиться, сам скачивает `Glasswing.exe`, сверяет его SHA-256 с файлом `Glasswing.exe.sha256` из того же релиза и заменяет себя. Проверить вручную можно в меню значка в трее: «Проверить обновления».

## Сборка

C# 7.3, WinForms, .NET Framework 4.8. Собирается PowerShell 7 (в нём уже есть компилятор Roslyn) на Windows или Linux:

```
pwsh build.ps1 -RefDir <папка со сборками-описаниями .NET Framework 4.8>
```

Сборки-описания берутся из пакета NuGet `Microsoft.NETFramework.ReferenceAssemblies.net48`. Готовый файл: `out/Glasswing.exe`.

## Выпуск версии

1. Поднять `Version` в `src/App.cs` и версии в `src/Program.cs`.
3. Отправить это в `main`: GitHub Actions соберёт exe, посчитает SHA-256 и создаст релиз `vX.Y` с тегом. Если такой релиз уже есть, ничего не произойдёт.
3. Поставить тег `vX.Y` и отправить его: GitHub Actions соберёт exe, посчитает SHA-256 и создаст релиз.

Рисунки питомцев делают скрипты из `art/` (Python и Pillow).
